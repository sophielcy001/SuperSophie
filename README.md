# 知页 · 本地知识库

知页是本地优先的个人知识库。当前工作源码版本为 0.50.14，支持页面树、块编辑、块引用与反向链接、全文检索、历史与回收站、附件、数据库和模板。日常编辑和检索使用本机 SQLite，启动与使用无需账号。

近期优先实现和验收 Windows x64 版本。当前 Windows 安装候选为 0.50.14 Beta。

[Windows 安装与验收](docs/Windows验收.md) · [Windows x64 常规安装包](artifacts/Zhiye-0.50.14-win-x64-setup.exe) · [Windows x64 离线安装包](artifacts/Zhiye-0.50.14-win-x64-offline-setup.exe) · [Mac 安装与使用](docs/macOS使用与验收.md) · [发布说明](docs/发布说明.md)

0.50.14 常规包通过默认新版微软拼音的标题、正文、切页及重开验收。离线包通过缺少 WebView2 的断网首装和运行时复用。[拼音实装报告](.verify/windows-0514/复验.md) [离线实装报告](.verify/windows-offline-0514/复验.md)

## 使用数据库

1. 在侧栏点击「新建数据库」，输入数据库名。普通页面的「页面操作」中也可以新建子数据库。
2. 点击「新建记录」，在普通页面编辑器中输入标题和正文。通过面包屑返回数据库，点击记录标题即可重新打开同一页。
3. 用「管理属性」添加字段。点击记录右侧的铅笔，或记录页上的「编辑属性」，填写记录属性。附件字段可以选择该记录页已导入的文件。
4. 在表格、看板、列表、日历、画廊和时间线之间切换。在「新建视图」可添加同类型的自定义视图。正文「插入 → 数据库视图」可嵌入保存视图。六种视图共用记录。[数据库视图指南](docs/数据库视图.md)

更改已有属性类型时，先在「管理属性」查看转换预览。确认前可查看将留空的记录和受影响的模板、视图。原值可在记录历史中查看。[转换属性类型](docs/数据库视图.md#转换属性类型)

「管理属性」中的「汇总」按关联计算计数、求和、最小值、最大值或平均值。「公式」用 `prop("属性名称")` 引用同一条记录的属性。输入变化后，后台更新记录和视图中的计算结果。[公式与汇总规则](docs/计算属性.md)

普通页面的编辑方式与记录页一致。在空白段输入 `/`，或点击「插入」选择块。Windows 用 `Ctrl+S` 立即保存、`Ctrl+K` 搜索。macOS 对应快捷键使用 `⌘`。页面可单独导出 Markdown。

用「页面操作 → 页面外观」更换图标。封面可从本页的图片附件选择。「导入图片」会先把原件加入附件列表，点击「保存外观」应用图标和封面。要移除封面，选择「无封面」并保存，原件仍可从「附件」取回。恢复历史修订会一同恢复当时的图标与封面。导出 Markdown 时，封面图片作为正文前的相对图片链接保存。[页面数据格式](docs/数据格式.md#工作空间)

用 `Ctrl+Shift+P` 或 `⌘⇧P` 打开命令面板。页面树支持方向键，专注模式可收起侧栏和页面操作。可在工作空间菜单的「外观」切换深浅主题或跟随系统。[键盘与外观](docs/键盘与外观.md)

从同一个菜单插入折叠、提示、LaTeX 公式、页内目录、附件卡片和保存视图。目录可以跳到收起块内的标题。桌面 Markdown 导出会写入相对链接并复制正文中引用的原件。[内容块指南](docs/内容块.md)

## 移动正文块

- 指针停在正文块上时，可拖动左侧手柄调整块在本页的位置。插入线显示松开后的落点。靠近滚动区域边缘可继续移动到屏幕外的内容，按 `Esc` 取消。
- 列表项和容器内的同级块使用右侧手柄。拖动整个列表、引用或表格时，其内容一起移动。
- 将光标放在要移动的块里，使用工具栏的「上移块」「下移块」，或按 `Alt+Shift+↑`／`↓`。macOS 上 `Alt` 对应 `Option`。移动可单次撤销或重做，保存后搜索仍能定位到原块。

## 正文图片、表格与网页链接

- 用「插入 → 图片」选择本地文件，也可以向正文粘贴或拖放图片。在页面附件的图片预览里选择「插入正文」，可使用同页已保存的原件。选中正文图片后，用「图片说明」修改可检索的说明。正文支持 PNG、JPEG、GIF、WebP 和 BMP，每张上限 24 MiB。
- 用「插入 → 表格」新建简单表格。在单元格里输入正文，用表格工具增删行列或切换表头。粘贴 HTML 表格或制表符分隔的数据可填入正文。
- 用编辑工具的「网页链接」给选中的文字填写 HTTP 或 HTTPS 地址。按住 `Ctrl` 或 `⌘` 点击链接可从系统浏览器打开。Markdown 导出会将正文图片复制到同目录的 `zhiye-images-…` 文件夹。移动导出的文件时，同时带上图片文件夹。

## 搜索和定位

打开「搜索」，输入标题、正文片段或代码符号。搜索结果显示命中的原文和上级路径。用方向键选中结果后按 Enter，或点击结果。标题命中打开页面，正文命中时滚动到对应块。

页面较多时，侧栏先显示部分同级页面和当前页的路径。可展开目录、用「显示更多页面」加载同级条目，或从搜索直接打开目标。

工作空间中的普通 PDF 会在后台提取文字层。搜索的 PDF 命中可直接打开原件的对应页。附件列表显示等待提取、无文本、部分成功或提取失败等状态。[PDF 检索与页码链接](docs/PDF检索.md)

页面操作中的「页面链接」和搜索结果中的「定位链接」提供可复制的 `zhiye://` 地址。关联协议后，打开地址可从外部应用进入知页的相应页面或正文块。[定位链接](docs/定位链接.md)

用「插入 → 块引用」选择同一工作空间的源页面与正文块。在引用卡片上点击来源标题可打开原块编辑。页面操作中的「反向链接」可返回引用该页或其中正文块的位置。[块引用与反向链接](docs/定位链接.md#块引用与反向链接)

数据库「管理属性」可新建「关联」，选择同工作空间的目标数据库。勾选同时创建反向关联后，可从任一端编辑记录的关联。记录属性里用「添加关联」按标题查找，点击已关联的标题可打开目标记录。外部集成修改或归档目标后，重新打开当前记录即可刷新关联显示。[关系字段格式](docs/数据格式.md#记录关联)

用「按数据库属性筛选」选择数据库、属性和条件。搜索窗口的「重建索引」可重新扫描当前工作空间。旧库升级或从备份恢复后，待处理页数会在搜索窗口显示。

## 导入、整理和复用

- 在侧栏点击「导入资料」并选择放入位置。可以同时导入多个 UTF-8 Markdown 文件。同批次能识别的文件链接可在知页中打开。导入报告可保存为文本，已导入的原件可以从附件中取回。
- CSV 可以创建数据库，也可以追加到现有数据库。第一行填写列名。标题取自「标题」或 `Title` 列，缺少这两列时用第一列。新库的其他列保存为文本，追加时按数据库属性名称和类型转换。导入报告列出跳过的行、无法匹配的列、转换失败和重复文件。
- 同一入口支持 Notion 的 Markdown 与 CSV ZIP，以及 Obsidian 资料库目录。知页迁入可识别的页面、数据库、链接和附件，报告列出转换、失配和能取回的原件。[迁移导入指南](docs/迁移导入.md)
- 在「页面操作」选择「导出 Markdown」或「导出 HTML」。正文及同目录的配套文件夹可一起移动。HTML 可离线阅读。配套文件夹内的 `导出报告.txt` 列出正文转换、源链接和附件原件。[通用导出格式](docs/数据格式.md#通用导出)
- 在数据库点击「导出 CSV」，选择整个数据库或当前视图。当前视图导出所有符合筛选条件的记录。导出报告和属性中的附件原件放在同目录的 `zhiye-csv-…` 文件夹。
- 用侧栏的「批量整理页面」勾选页面，再移动或归档整组分支。在数据库的「批量选择」中可跨表格、看板或列表选择记录。回收站可以逐项恢复，也可以恢复所选分支。
- 点击页面右上角的星标添加收藏。在侧栏打开「最近访问」找回已访问的页面。点收集箱右侧的加号快速新建，或在页面操作中把当前页或数据库设为收集箱。
- 在普通页面或记录的「页面操作」中保存模板，再从侧栏「模板」或目标页面的操作菜单创建副本。页面正文、子页、附件和适用的记录属性会复制到新页面。

## 备份与恢复

侧栏「备份与恢复」可创建 `.zhiye-recovery.zip` 整库包，保存数据库、历史、集成审计和附件原件。自动备份默认每日检查，可定制目标目录和保留数量。升级前在本机保存一份整库包。

「从备份恢复」可打开整库包、`.zhiye.zip` 内容包和旧版 `.zhiye.json`。恢复会创建独立工作空间，保留包内对象 ID。整库恢复后需给外部脚本重新授权。[备份设置与故障恢复](docs/故障恢复.md)

「导出工作空间」默认携带修订历史。取消「内容包包含修订历史」后，导出的内容包只保留各页当前修订，并保留正文、结构和附件。[内容包格式](docs/数据格式.md#原生工作空间包)

要把内容迁入已打开的工作空间，选择「备份与恢复 → 合并内容包」。可以选择 `.zhiye.zip` 或旧版内容 JSON。知页会创建独立的导入分支，为对象分配新 ID，并重写包内关系和链接。合并结束后可从同一面板查看批次结果。[操作与重试](docs/故障恢复.md#合并到当前工作空间)

可从侧栏「回收站」恢复归档页面，或复核页数后选择清空。「检查附件清理」登记无引用的原件，七天后再次检查并确认即可释放空间。[清空与恢复](docs/故障恢复.md#清空回收站与清理附件原件)

## 接入本机脚本与 MCP 客户端

从「切换工作空间 → 集成与 API」选择授权资源、生成集成令牌并启用本机 API。脚本可以列举授权资源、续读增量变化、搜索、查询数据库、读写页面及传输附件。授予「提交修改建议」后，也可将候选标题、属性或正文交给本地用户审阅。建议可从页面操作或集成设置打开，接受后能在页面历史查看来源。API v1 自 0.26.0 起采用稳定契约。[本机 API v1](docs/本机API.md) [OpenAPI](docs/openapi.v1.yaml)

缓存引用预览或记录关联的客户端可从增量变化中接收 `derived.invalidated`。事件指向需要刷新派生内容的页面，原始修订仍用于正文和属性更新。[变更与缓存](docs/本机API.md#编目与增量缓存)

运行 `npm run build:integrations` 构建 TypeScript SDK 和 stdio MCP 适配器。接入指南包含客户端配置、八个工具、脚本示例、游标重建和已验收版本。[MCP 与 SDK](docs/MCP与SDK.md)

## 从源码构建

需要 Node.js 24 和项目锁定的 Rust 1.100.0。依赖版本由 `package-lock.json` 与 `Cargo.lock` 固定。

在离线机器上构建时，先在同系统与架构准备锁定依赖的缓存。[离线构建与验收](docs/离线构建与验收.md)

### macOS

安装 Apple Silicon 版本时，打开 DMG 并将「知页」拖到 Applications。新版本提供中文原生菜单，支持 ⌘N 新建页面、⌘S 保存、⌘K 搜索及 ⌘⇧P 命令面板。[Mac 使用与验收](docs/macOS使用与验收.md)

在安装 Xcode 命令行工具后，从源码执行以下命令。

```sh
npm ci
npm test
npm run release:mac
```

发布入口生成当前 Mac 架构的 Release 应用，完成本机 ad-hoc 签名与校验后封装 DMG。默认输出到 `artifacts`。测试时在启动前设置 `ZHIYE_DATA_DIR`，为合成资料使用独立目录。默认数据在 `~/Library/Application Support/org.zhiye.desktop/workspaces`。[Mac 发布入口](scripts/macos-release.mjs)

### Windows x64

0.50.14 Beta 提供未签名 NSIS 候选安装包，供 Windows 10 及以上 x64 实机验收。[常规安装包](artifacts/Zhiye-0.50.14-win-x64-setup.exe) [离线安装包](artifacts/Zhiye-0.50.14-win-x64-offline-setup.exe) [校验与验收步骤](docs/Windows验收.md)

把整套文件移到测试机时，可使用包含安装包、锁定源码、合成素材及依赖缓存的验收 ZIP。[Windows 验收包](artifacts/Zhiye-0.50.14-windows-acceptance.zip) [使用说明](docs/Windows验收包.md)

安装 MSVC 工具链、Visual Studio C++ 构建工具、Windows SDK 和 WebView2 Runtime。PowerShell 中运行以下命令。

```powershell
npm.cmd ci
.\scripts\windows-dev.ps1 test
.\scripts\windows-dev.ps1 build
```

构建脚本按工作源码版本命名产物，当前输出 `artifacts\Zhiye-0.50.14-win-x64.exe`。用 `.\scripts\windows-dev.ps1 installer` 构建常规 NSIS 安装包，或用 `.\scripts\windows-dev.ps1 offline-installer -WebView2InstallerPath $runtime` 嵌入已核验的微软运行时。用 `.\scripts\windows-dev.ps1 dev` 启动开发窗口。[运行时来源与构建步骤](docs/Windows验收包.md#从源码重建两种安装包) [Windows 验收流程](docs/Windows验收.md)
