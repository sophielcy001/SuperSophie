# 知页 Mac 版

当前可安装版本为 0.49.0 Mac Beta，面向 Apple Silicon。打开 DMG，把「知页」拖到 Applications，再从应用程序目录启动。0.50.0 的系统普通退出保护已进入源码，等待 Mac 成品验证。[下载 DMG](../artifacts/Zhiye-0.49.0-macos-arm64.dmg) [SHA-256](../artifacts/Zhiye-0.49.0-macos-arm64.dmg.sha256) [交付源码](../artifacts/Zhiye-0.49.0-source.zip) [开发进度](../开发进度.md)

## 安装与数据

在终端用 `shasum -a 256 -c Zhiye-0.49.0-macos-arm64.dmg.sha256` 核对同目录的镜像。此包使用本机 ad-hoc 签名。Apple 公证和跨机器的 Gatekeeper 安装体验待验证。[Tauri 的 Mac 签名说明](https://v2.tauri.app/distribute/sign/macos/#ad-hoc-signing)

默认资料目录为 `~/Library/Application Support/org.zhiye.desktop/workspaces`。安装应用与升级应用时，资料独立保存在该目录。通过「备份与恢复」另存整库包，再将新应用放到应用程序目录。恢复包会创建独立工作空间，并要求给外部集成重新授权。[备份与恢复](故障恢复.md)

镜像面向 Apple Silicon。Intel Mac 可从源码使用对应的原生 Rust 工具链构建，Intel 成品运行待单独验证。

## 原生菜单和快捷键

「文件」菜单可以新建页面、新建数据库、保存、导入资料及打开备份。「显示」菜单提供搜索、命令面板与专注模式。「编辑」菜单使用系统的剪切、复制、粘贴、撤销与重做。

| 操作 | 快捷键 |
|---|---|
| 新建页面 | ⌘N |
| 新建数据库 | ⌘⇧N |
| 保存 | ⌘S |
| 搜索 | ⌘K |
| 命令面板 | ⌘⇧P |
| 专注模式 | ⌘⇧F |
| 关闭窗口 | ⌘W |
| 退出知页 | ⌘Q |

新建和导入沿用编辑器的提交检查。在 0.49.0 中，关闭窗口或通过应用菜单及 ⌘Q 退出，会先提交当前页标题与正文。若已显示「保存失败」，请在原页重试或导出草稿。0.49.0 从活动监视器执行普通「退出」时可能丢失尚未提交的草稿。独立属性表单需在表单中确认保存。没有可打开的工作空间时，仍可从「备份与恢复」进入恢复操作。[中文输入和键盘](键盘与外观.md) [保存故障与草稿](故障恢复.md)

进入工作空间时会打开最近访问且仍有效的页面。首次使用或没有可用的访问记录时，打开该空间的第一张有效页面。

## 从源码生成安装包

在 Mac 安装 Xcode 命令行工具、Node.js 24 和项目锁定的 Rust 工具链。在源码根目录执行以下命令，构建当前 Mac 架构。

```sh
npm ci
npm test
npm run release:mac
```

构建入口生成 Release 二进制，在本机临时目录创建并校验签名后的应用，再生成 DMG 和 SHA-256。默认写入 `artifacts`。用 `npm run release:mac -- /你的输出目录` 指定另一目录。共享盘上的项目可把 `TMPDIR` 设为本机目录，`CARGO_TARGET_DIR` 指向构建缓存。[Mac 发布入口](../scripts/macos-release.mjs) [离线缓存](离线构建与验收.md)

## 本机验收

从交付 DMG 复制应用到独立测试目录，用合成资料执行菜单新建、正文编辑、保存、退出重开、搜索和外部定位链接。通过系统面板验证附件选择、Markdown 导出与独立恢复。记录系统版本、CPU、架构、应用哈希和实际错误。原有容量故障、中文输入、历史、备份及接口验证可在 Mac 上继续复验。[首版验收记录](../1.0验收记录.md)

0.49.0 在 macOS 26.5.1、Apple M4、16 GiB 上验证。24 项 npm 测试、93 项真实 Core 界面联调通过；交付 DMG 的原生菜单、中文编辑、搜索、模态保护、整库恢复、Markdown 导出、跨空间定位及退出重开已实测。恢复的 6 页及历史与源空间一致，退出前正文保留至新修订。Mac 11.0 是构建最低目标，旧系统运行、Intel、跨机器安装与 Dock 退出均需另行实测。
