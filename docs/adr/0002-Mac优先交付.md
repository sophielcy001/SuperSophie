# ADR 0002 · Mac 优先交付

2026-11-19 用户将近期交付顺序调整为 Windows 优先。[最新决策](0003-Windows优先交付.md)

2026-11-18 用户在 Windows 环境问题的回复中要求「先做mac版本，修改进化」。近期开发、安装交付与原生验收以 macOS 为主。知识库的编辑、数据库、检索、附件、备份、公开格式和授权接口继续按现有设计推进。

当前可用开发机为 Apple Silicon Mac。先提供经过实际安装与操作的 arm64 Release 镜像，补齐 Mac 菜单和发布入口。Intel 的源代码入口保留独立实机验证范围。跨设备同步、团队协作及后续候选能力按原计划各自条件立项。

Mac 验收记录与当前安装件决定近期交付结果。Windows 的既有候选包、缓存和待验步骤保留其版本与平台范围，后续在环境可用时接续。[Mac 使用与验收](../macOS使用与验收.md) [原设计基线](../../个人资源管理系统_完整开发Plan_v2.0.md)
