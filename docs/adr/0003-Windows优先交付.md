# ADR 0003 · Windows 优先交付

2026-11-19 用户要求「修改为先实现windows版本」。近期开发、安装交付与原生验收以 Windows x64 为主。首版功能范围、数据格式和验收门槛沿用原开发计划。[开发计划](../../个人资源管理系统_完整开发Plan_v2.0.md) [首版验收](../../1.0验收记录.md)

1. 在 Windows 参考机上从当前源码构建桌面应用。使用隔离合成库验证 WebView2、页面和附件、保存及重启，记录可复现的问题。
2. 先完成 Windows 常规与离线 NSIS 包的本机重建，再核对新装、覆盖升级、协议注册、恢复和离线运行。实测使用专用测试账户或快照。
3. 按验收表补齐系统中文输入、讲述人、真实保存故障、系统文件对话框、迁移导入和性能。依据实测结果更新 Windows 交付状态。

Windows 本轮从 0.48.0 候选接续，已从 0.50.0 源码生成新安装候选。Mac 已验收版为 0.49.0 Beta，0.50.0 的 AppKit 退出保护继续留在源码，Mac 成品复验排在 Windows 交付之后。[Windows 验收](../Windows验收.md) [Mac 使用](../macOS使用与验收.md) [开发进度](../../开发进度.md)
