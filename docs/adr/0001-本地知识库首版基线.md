# ADR 0001 · 本地知识库首版基线

2026-11-16 记录，适用于知页 0.34.0 Beta。对应 KB-001 与 KB-009，设计基线来自《个人资源管理系统_完整开发 Plan v2.0》的范围、架构、许可和待验证决策。[设计依据](../../个人资源管理系统_完整开发Plan_v2.0.md#01-需求依据) [里程碑](../../个人资源管理系统_完整开发Plan_v2.0.md#7-里程碑与发布边界)

## 用户确认的方向

- 主要产品是类 Notion 的个人知识库，日常流程围绕编辑、组织、检索和迁移资料。Agent 由外部工具运行，按用户授予的范围使用知识库接口。
- 本地优先，以 Windows 为首发平台，后续支持自托管同步。
- 全部自研产品组件进入开源范围，包括后续自研服务端及其部署配置。[开源范围](../../个人资源管理系统_完整开发Plan_v2.0.md#101-开源边界)
