# 计算属性

在数据库「管理属性」新建「汇总」或「公式」。计算结果以只读字段显示在记录页、表格、看板和列表。外部集成修改数据后，可在记录页点「刷新计算结果」，或重新打开数据库。

## 汇总

先选择一项同工作空间的关联。计数取当前可读的关联记录数，包括相关数值为空的记录。求和、最小值、最大值和平均值需要选择目标数据库的数字属性或计算属性。它们跳过空值，遇到可读目标的非数字或计算错误时显示相应错误。空集合的计数及求和为 0，最小值、最大值、平均值为空。

目标归档或失去授权后，从计算输入中移除。看不到任何目标的集成取得与空集合相同的结果。获得资源范围内的单条记录即可纳入该条记录的计算。其余关联成员及其变动由授权过滤。[本机 API](本机API.md#计算属性)

## 公式

`prop("实际数量") * 2` 读取同一条记录的属性。「插入属性」在光标处插入引用。保存把名称解析为稳定的属性 ID，之后改名仍引用同一个字段。标题也可用 `prop("标题")` 引用，单选与状态属性返回显示文字。创建和修改时间以 UTC Unix 毫秒表示。数组值无法直接参与公式，关联记录先用 Rollup 聚合，附件依赖按读取权限处理。

表达式接受十进制数字、双引号字符串、`true`、`false`、`null` 和括号。运算符从高到低为一元负号及 `!`、`* /`、`+ -`、`< <= > >=`、`== !=`、`&&`、`||`。同级二元运算从左到右。算术要求数字，比较要求相同类型。算术及有序比较遇到空值返回空值。等值比较视两个空值相等。`&&`、`||` 及 `if` 的条件要求布尔值，只执行必要分支。

| 函数 | 规则 |
|---|---|
| `if(条件, 值, 值)` | 选择分支并计算该分支。 |
| `coalesce(值, 默认值)` | 仅当第一个值为空时计算默认值。 |
| `isEmpty(值)` | 当值为 `null` 或空字符串时为真。 |
| `text(值)` | 将数值、布尔值转换为文本，文本仍返回原值。 |
| `length(文本)` | 返回 Unicode 字符数。 |
| `lower(文本)`、`upper(文本)` | 转换大小写。 |
| `concat(文本, 文本)`、`contains(文本, 文本)` | 拼接两个文本，或判断第一个文本是否包含第二个文本。 |
| `date(文本)` | 验证并返回 `YYYY-MM-DD` 全天日期。 |
| `year(日期)`、`month(日期)`、`day(日期)` | 返回日期的年、月、日。 |
| `daysBetween(起始日期, 结束日期)` | 按日历日期计算天数，结束日期在起始日期之前时为负数。 |
| `utcDate(毫秒)` | 把整数 Unix 毫秒转换为 UTC 日期。 |

除条件、默认值和判空函数外，任一参数为空时，函数返回空值。日期采用公历，对时区不敏感的全天值原样处理。表达式只调用表中的函数和 `prop`。解析器限制表达式为 8,192 字节、256 个标记、32 层解析嵌套。每个计算值最多执行 2,048 次求值步骤和 64 层求值嵌套，文本结果最多 2,048 个 Unicode 字符。

| 代码 | 含义 |
|---|---|
| `CYCLE` | 求值重新进入当前路径上的同一记录、同一属性。 |
| `LIMIT_EXCEEDED` | 表达式、求值步数、嵌套层数或文本结果超限。 |
| `RESTRICTED` | 求值需要未获授权的属性。 |
| `TYPE_ERROR` | 参数或结果类型与运算要求不同。 |
| `DIVISION_BY_ZERO` | 除数为零。 |
| `OUT_OF_RANGE` | 运算产生无法表示的数值。 |
| `INVALID_DATE` | 日期文本或转换后的年、月、日无效。 |

## 后台重算

改动记录或计算属性后，知页和原始数据一起保存重算任务。后台按依赖索引分批更新计算结果。已有结果的输入变化时，计算列暂时显示「计算中…」。记录面板和数据库视图会自动刷新。首次读取缺少缓存的结果时，知页在当前快照上计算结果。

重算改动的是计算表示版本。引用该输入的记录保留原始修订、正文和写入 ETag。外部集成的缓存按当前授权区分，隐藏记录的数值变化不会改变其他读者的结果、计算时间或待计算状态。后台失败时保留任务并退避重试，重新打开知页后继续处理。外部读取的状态及刷新方式见[本机 API](本机API.md#计算属性)。

原生工作空间包保存计算规则。恢复后按需建立缓存。CSV 按导出时的一致性快照计算标量或错误代码，追加到既有数据库时把计算列记为未匹配。[数据格式](数据格式.md) [开发记录](../开发记录.md)
