# 知页 Beta 发布说明

知页是本地优先的个人知识库。当前 Windows x64 安装候选为 0.50.14 Beta 的 WebView2 HTTPS 修复批次。Mac 已验收版为 0.49.0 Beta。[Windows 验收](Windows验收.md) [Windows 常规安装包](../artifacts/0.50.14-windows-WebView2-HTTPS/Zhiye-0.50.14-win-x64-setup.exe) [Windows 离线安装包](../artifacts/0.50.14-windows-WebView2-HTTPS/Zhiye-0.50.14-win-x64-offline-setup.exe) [Mac 使用与安装](macOS使用与验收.md)

## 近期改动

Windows 常规安装器在缺少 WebView2 时通过系统 HTTPS 接口下载微软引导程序，下载或文件检查失败时停止安装。需要断网安装时请使用内置微软运行时的离线包。[安装器与复验](../.verify/windows-current-runtime-fallback-0514/复验.md)

Windows 0.50.14 在卸载失败页提供简体中文和英文的删除失败提示。主程序无法删除时保留安装登记，恢复文件访问权限后可以重新卸载。[本轮实装与下载校验](../.verify/windows-uninstall-feedback-0514/复验.md)

Windows 0.50.14 草稿保护构建会在知页仍被占用时停止覆盖安装、维护和卸载。中英文构建随系统选择简体中文或英文，提示先保存编辑并正常退出。两种安装器在简体中文 Windows 通过六项原生向导草稿保护，缺少语言值时可直接进入卸载向导。离线安装器在无 WebView2 的 Windows 10 断网客机通过首装和重装复用。[中英文验收包与校验](../.verify/windows-installer-l10n-0514/复验.md) [断网实装](../.verify/windows-l10n-runtime-0514/复验.md)

Windows 0.50.14 修复默认新版微软拼音在预填标题与正文上的组字问题。常规包在 Windows 10 客机用原生点击和微软拼音通过取消、确认后切页及重开。离线包通过无 WebView2 的首装、复用和从开始菜单早期关闭。[拼音复验](../.verify/windows-0514/复验.md) [离线复验](../.verify/windows-offline-0514/复验.md)

Windows 0.50.13 修复选择页面引用后立刻切页时写错页的问题。引用保存到发起页，切换到的页面保持原修订。[Windows 复验](../.verify/windows-0513/复验.md)

Windows 0.50.12 将备份面板内的共享路径和盘符路径显示为常规 Windows 路径。「最近成功」的路径可直接用于系统恢复窗口。

Windows 0.50.11 减少大型资料库页面清单的桌面传输量，保留完整字段和页面顺序。十万页工作构建实测 JSON 体积减少 34.4%。压力复验分别检查原始启动和追踪刷新。

Windows 0.50.10 在复用当天备份时会重试先前失败的旧包清理。解除文件占用后，后台检查和「立即运行备份」都可继续清理，并保留已校验的当天备份。

Windows 0.50.10 的安装器在主程序或随包资源无法写入时停止安装，并保留原有安装登记。解除文件占用后可重新运行安装器。

Windows 0.50.9 将备份状态读取放到独立任务中。自动备份中断恢复时，程序先登记已校验的恢复包，再执行保留策略。Chromium 验收夹具补齐了备份状态命令。

Windows 0.50.8 修复文件和备份状态写入时的容量误报，以及自动备份状态日志写入失败时的无提示。桌面保留上次成功备份并显示具体原因，恢复写入后可重试。源码中的本机 API 契约示例可以随工作区一起编译。

Windows 0.50.1 修正附件落盘目标不可用时的错误提示。构建入口从 Cargo 获取实际应用路径，支持自定义输出目录。Windows PowerShell 5.1 按 UTF-8 读取 Tauri 配置，离线安装包沿用 Cargo 设置的目标目录。[附件复验](../.verify/a06-windows-050/复验.md) [构建入口复验](../.verify/windows-build-output/复验.md)

Windows 0.50.2 在覆盖安装后清理旧版动态 WebView2 加载器。安装器验证原安装登记与 DLL 的完整指纹，保留新装目录中原有的同名文件及内容不同的文件。[清理回归](../.verify/windows-loader-cleanup/复验.md)

Windows 0.50.6 优化了大型资料库的全文搜索和首轮索引，减少 PDF 状态读取的重复扫描。全库文本按页面与修订聚合后读取分页所需的原文。既有资料库可原位打开。[十万页样本与对照](../.verify/windows-search-scale/复验.md)

Windows 0.50.7 为验收包加入锁定的 NSIS 3.13、Tauri NSIS 插件 0.5.3 和对应源码。重建两种安装包时可使用同一个验收 ZIP 提供的缓存。工作源码的原生验证也提高了 WebView2 回环发现和多文件选择的稳定性。[验收包重建](Windows验收包.md#从源码重建两种安装包) [WebView2 和文件窗口复验](../.verify/windows-library-0506/复验.md)

Windows 0.50.5 修复了本机 API 偶发使用 Fetch 禁用端口的问题。知页在开始监听前核对系统分配的端口，TypeScript SDK 可以继续使用界面显示的连接地址。[问题复现和修复证据](../.verify/windows-fetch-port/复验.md)

Windows 0.50.4 修复了覆盖安装和卸载的短暂文件占用处理。覆盖时重试读取新版文件版本，核对后再清理已知旧加载器。Restart Manager 返回 350 后在新会话复查，资源释放后可继续。卸载失败时保留原卸载入口供重试。[Windows 安装器证据](../.verify/windows-0504/复验.md)

Windows 0.50.3 将保存失败的错误正文设为具名的独立告警。重试、导出草稿、另存和关闭继续作为独立的操作按钮。[修复对照](../.verify/a02-windows-0502/复验.md#保存失败告警)

Mac 在 0.49.0 加入「文件」「编辑」「显示」「窗口」菜单，支持菜单新建、保存、搜索和命令面板。发布入口构建 Release 应用，在封装 DMG 前检查应用签名与版本。安装镜像中提供 Applications 入口。[Mac 使用与验收](macOS使用与验收.md)

进入工作空间时回到最近访问的有效页面。空的访问记录仍可打开首张页面，已归档的内容继续按回收站规则处理。

本次镜像为 Apple Silicon 原生构建，使用本机 ad-hoc 签名，尚未通过 Apple 公证。Intel Mac 运行与跨机器安装待单独验证。独立属性表单需在表单中确认保存；关闭窗口与菜单退出保护当前页面的标题和正文。

0.48.0 起，归档源码的 Windows 构建入口可生成内置 WebView2 的离线安装包。入口校验微软独立安装程序的 SHA-256，分别保存常规和离线构建产物。[两种安装包的重建步骤](Windows验收包.md#从源码重建两种安装包)

0.47.0 起，Windows 安装包按 WebView2 的有效注册版本判断运行时是否存在。启动运行时安装程序失败、返回错误或结束后仍无有效版本时，知页安装停止复制应用文件，并保留诊断信息。[断网安装验收](Windows验收.md#a17-断网安装)

0.46.0 起，Windows 离线构建使用备用 Rust 工具链时，保留已设置的 `CARGO_HOME` 和 `RUSTUP_HOME`。构建脚本以带 BOM 的 UTF-8 保存中文提示，兼容 Windows PowerShell 5.1 的文件读取规则。[离线构建步骤](离线构建与验收.md#windows-x64-离线源码构建)

0.45.0 起，记录属性保存冲突时，可以按字段对比已保存值与本机草稿。重新提交时核对最新修订，关联保留另一次写入增加的成员。未保存的属性也可以导出为带基准修订的草稿。[解决记录属性冲突](数据库视图.md#解决记录属性冲突)

0.44.0 起，本机 API 提交修改后，已打开的数据库、记录属性和正文嵌入视图会自动刷新。重算期间显示计算状态，结果可用后自动显示。记录编辑表单保留已填内容，提交时继续检查原始修订。[计算属性](计算属性.md)

0.43.0 起，任务复选框使用自身首段的中文名称，页引用可以作为名称，首段为空时读作「空白任务」。修改文字后名称随之更新，复选框继续报告勾选状态。[输入法与键盘](键盘与外观.md)

0.42.0 起，从导入报告查看原件时，关闭预览或按 Esc 会回到同一份报告，可以继续查看失配和降级明细，或保存 TXT。[迁移导入](迁移导入.md)

0.41.0 修复恢复归档分支时被当前保存错误拦住的问题。恢复会保留本机草稿，之后可对比版本并提交。保存失败时可先导出草稿，再确认关闭当前页面。[故障恢复](故障恢复.md#编辑过程中出现保存失败)

0.40.0 修复了 macOS 将草稿、Markdown、HTML、CSV、原件、内容包和导入报告保存到部分 SMB 共享目录时失败的问题。目标卷拒绝完整同步时，应用使用该卷支持的 POSIX 文件同步，完成同步后发布文件。

0.39.0 起，Core 存储实例关闭时显式释放资料库的写锁。用受控子进程复验了关闭后立即重开、已提交页面的读回，以及已有写入者运行时拒绝第二个实例。[工作空间格式](数据格式.md#工作空间)

0.38.0 起，「管理属性」可为既有可填写字段更换类型。确认前列出将留空的值和受影响的模板、视图。SQLite 格式 21 保留旧修订中的原属性定义。含这些修订的内容包使用 ZIP v9，可独立恢复或合并。[转换操作](数据库视图.md#转换属性类型) [数据格式](数据格式.md#数据库与记录)

0.37.0 起，新建集成时可选择令牌有效期，集成列表显示到期时间和状态。到期后的请求返回 `401`，附件下载在分块鉴权时停止。SQLite 格式 20 引入有效期字段，旧授权迁移为手动撤销。[授权操作](本机API.md) [数据格式](数据格式.md#集成与修订来源)

0.36.0 起，Windows 常规和离线安装目录，以及 macOS 应用包的 `Contents/Resources`，均附带项目许可证 `LICENSE`、`THIRD_PARTY_NOTICES.md` 和 `licenses` 目录中的八份许可文本，可离线查阅。[第三方组件说明](../THIRD_PARTY_NOTICES.md)

0.35.0 起，自动备份复用当天的恢复包时会检查文件大小和修改时间。旧记录或文件有变化时会重新校验内容。点击「立即运行备份」会直接校验当天的包。发现损坏时生成新的恢复包，并保留旧文件供核对。[当日恢复包的校验](故障恢复.md#当日恢复包的校验)

0.34.0 起，CSV 导入报告按原文件的物理行号列出无法转换的值和跳过的记录。成功报告可直接查看保存的 CSV 原件，导出的 TXT 会记录原件名、页面和附件 ID。[CSV 格式与报告](数据格式.md#导入侧栏与模板)

0.33.0 起，中文输入法在标题和正文组字时会显示「输入法组字中」。选词确认后保存，取消时回到原内容。[输入法与键盘](键盘与外观.md)

## 0.32.0 起的数据与备份变化

- 「回收站」新增确认后清空。确认界面展示页数、分支数和受影响的记录。已清空的页面与块引用显示不可用，清空前的备份可恢复相应内容。[回收站操作](故障恢复.md#清空回收站与清理附件原件)
- 「检查附件清理」登记无引用原件。七天保留期满后再次核对范围，确认才移除原件。当前正文、保留历史、模板和在途备份需要的原件受到保护。[原件清理操作](故障恢复.md#清空回收站与清理附件原件)
- SQLite 工作空间格式升级到 19。含已清空对象标记的内容包写为 ZIP v8，恢复入口支持 ZIP v2–v8 及旧版内容 JSON。导出时可选择带修订历史或仅当前修订。[数据格式与兼容范围](数据格式.md) [本机 REST v1](本机API.md) [MCP 和 TypeScript SDK](MCP与SDK.md)

## 安装和升级

打开 Apple Silicon DMG 后，将「知页」拖到 Applications。资料独立保存在用户目录。升级前可从「备份与恢复」另存整库恢复包。[Mac 安装、快捷键与源码构建](macOS使用与验收.md)

0.50.14 提供未签名的 Windows 10 及以上 x64 NSIS 候选。常规包在缺少 WebView2 时通过 HTTPS 获取引导程序。约 226 MB 的离线包使用内置的微软 x64 Evergreen 安装程序。[常规包 SHA-256](../artifacts/0.50.14-windows-WebView2-HTTPS/Zhiye-0.50.14-win-x64-setup.exe.sha256) [离线包 SHA-256](../artifacts/0.50.14-windows-WebView2-HTTPS/Zhiye-0.50.14-win-x64-offline-setup.exe.sha256) [安装验收步骤](Windows验收.md)

打开旧工作空间时，知页先保存升级前的 SQLite 快照和整库恢复包。在「备份与恢复 → 升级前备份目录」可以查看文件。需要退回旧格式时，先为升级后的内容另存整库包，再把旧快照恢复到独立空间。恢复空间的历史集成令牌会禁用，新授权可在该空间单独创建。[升级与恢复步骤](故障恢复.md#工作空间升级失败)

0.50.14 已实装复验从 0.31.0 覆盖、格式 18 到 21 迁移、备份受阻后重试和两份独立恢复。回滚演练确认旧版拒读格式 21 副本，重装新版后可取回升级后提交的第 4 版和新增原件。[覆盖升级](../.verify/windows-upgrade-0514/复验.md) [实装回滚](../.verify/windows-rollback-0514/复验.md)

0.50.14 HTTPS 修复批次的交接 ZIP 提供本批安装包、冻结源码、合成素材、锁定依赖、联网首装及断网重建回执和可重算的 A18 补测。[同批交接 ZIP](../artifacts/0.50.14-windows-WebView2-HTTPS/Zhiye-0.50.14-windows-acceptance-handoff-verified.zip) [SHA-256](../artifacts/0.50.14-windows-WebView2-HTTPS/Zhiye-0.50.14-windows-acceptance-handoff-verified.zip.sha256) [解包与校验](Windows验收包.md)
