# 从 Notion 和 Obsidian 迁移

在知页侧栏打开「导入资料」，选择格式和放入位置。每次迁移在目标位置创建一个页面分支。迁移在本机读取原件、检查格式并暂存，校验完成后一次发布整个分支。导入完成后可从报告打开页面、查看原件或把完整报告存成 TXT。查看原件后关闭预览或按 Esc，可回到原报告继续检查。

## Notion

从 Notion 选择「Markdown 与 CSV」导出，并包含子页面。拿到 ZIP 后，在知页选「Notion ZIP（Markdown 与 CSV）」。知页支持存储和 Deflate 压缩条目，以及外层由 `Export-*.zip` 分卷和可选 `index.html` 组成的一层包装。[Notion 导出说明](https://www.notion.com/help/export-your-content)

- 正文兼容常见 Markdown 标题、段落、代码、列表、表格、图片和网页链接。页面与同名导出目录匹配后，目录下的页面成为该页子页。页面标题会去除 Notion 文件名末尾常见的 32 位 ID 或 UUID，报告仍显示原路径。
- CSV 创建数据库。记录标题依次查找「标题」、`Title`、「名称」和 `Name` 列，缺少这些列时使用第一列。其余列保存为文本。标准 Notion ID 文件名同时有完整 `_all.csv` 与筛选 CSV 时，完整表参与转换。CSV 记录与直属目录的 Markdown 标题两边唯一时合并正文和属性，歧义保留为独立页并在报告中说明。
- 相对链接解析到包内的页面或附件。数据库视图、关系、公式和权限按源文件留存，也取决于 Notion 实际导出的内容。HTML 页面、其他未转换格式和筛选 CSV 可从附件取回。ZIP 本体不超过 100 MiB 时，也会作为完整原件附在迁移分支首页。

## Obsidian

选择「Obsidian 资料库目录」，然后选择含 Markdown 笔记和附件的整个资料库。已有文件夹保留为知页层级。[Obsidian 内部链接](https://obsidian.md/help/links) [嵌入](https://obsidian.md/help/embeds) [附件](https://obsidian.md/help/attachments)

- 支持相对 Markdown 链接、包含路径的 Wiki 链接和 `[[目标|别名]]`。省略路径的 Wiki 链接需在资料库中唯一。同名歧义和缺页均保留原语法，报告显示来源文件、行号和失配总数。
- 可识别的内嵌图片和本机文件转为正文块。链接到笔记的嵌入转为页面引用。HTML 与 YAML 作为正文文本留存。插件配置、画布语义、附件显示尺寸、标题和块级定位按报告提示处理。正文可打开匹配到的页面。
- Canvas 和其他普通文件保留原件。`.obsidian`、`.trash`、`.git` 及常见系统元数据留在来源。

## 取消、重试与报告

从导入窗口可在发布前取消迁移。失败或关闭进程后，重新进入导入窗口可看到最近一批的问题，重新选同一来源即可重试。原件先写入基于 SHA-256 的本地存储，页面、属性、附件索引、提交凭据和完成状态在同一 SQLite 事务发布。

来源名称、所选父页及实际条目路径和内容哈希决定重复匹配。恢复原生 ZIP v5 后也能识别重复批次。参与导入的内容变化后再导入会生成独立分支。

一次最多读取 4,096 个条目、1 GiB 展开的原件和 32 级目录，可生成 10,000 个页面或记录。单源 Markdown、CSV 与普通附件分别最多 1、4 和 100 MiB。可转换 CSV 合计 64 MiB，生成正文 JSON 合计 128 MiB。超出附件上限、路径不合规、非普通文件、符号链接及不支持的 ZIP 条目留在来源并列入报告。导出范围和批次页面数超过上限时，整批失败并显示原因。
