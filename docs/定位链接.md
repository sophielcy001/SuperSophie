# 打开页面和正文块链接

在页面操作菜单中选择「页面链接」，或在搜索结果中选中一项后选择「定位链接」。选中地址即可复制。正文命中提供正文块链接，标题命中提供页面链接。PDF 命中提供指向特定原件版本与页码的链接。[PDF 文本检索](PDF检索.md)

在知页已关联 `zhiye` 协议的电脑上，打开链接会进入相应工作空间和页面。正文块链接会滚动并标注对应的块。页面改名或移动后仍可沿原链接定位，因为链接记录的是工作空间、页面与正文块的稳定身份。下面给出地址格式。

```text
zhiye://open/workspaces/<工作空间 UUID>/pages/<页面 UUID>
zhiye://open/workspaces/<工作空间 UUID>/pages/<页面 UUID>/blocks/<正文块 UUID>
```

应用运行期间收到新链接会先保存当前编辑。保存失败时可从当前编辑器解决冲突或导出草稿，再打开目标链接。块已移除时打开所属页面并提示。页面已归档时提示从回收站恢复。链接通过本机应用打开，所指工作空间需存在于当前数据目录。

REST 搜索、页面和块接口返回 `page_link`，正文命中和精确块接口还返回 `block_link`。MCP 和 SDK 可读取相同字段。程序通过 `page_path`、`block_path` 配合当前监听地址和令牌请求受权内容。PDF 命中提供 `pdf.link` 和原件下载路径。桌面地址使用稳定 ID、原件哈希和页码，可在本机 API 关闭后打开。[本机 API](本机API.md) [MCP 与 SDK](MCP与SDK.md)

macOS 使用应用包内的协议声明。Windows 安装包使用协议关联，并将运行中收到的链接交给当前窗口。可在 Windows 运行 `.\scripts\windows-dev.ps1 installer` 生成 NSIS 安装程序。安装与运行验收以项目进度为准。[Tauri 协议关联与事件](https://v2.tauri.app/plugin/deep-linking/) [Tauri 单实例转发](https://v2.tauri.app/plugin/single-instance/) [开发进度](../开发进度.md)

## 块引用与反向链接

1. 在引用页使用「插入 → 块引用」，或在空段落输入 `/` 后选择「块引用」。选择当前工作空间中的页面，再选择具体的源块。
2. 卡片显示只读的源内容。点击来源标题跳到原块编辑。引用页在前台时会刷新卡片，源块恢复后原卡片自动重新显示。嵌套的块引用在卡片内显示为占位。删除卡片只会删除这一处引用。
3. 在任意页打开「页面操作 → 反向链接」。列表同时显示指向当前页和其中正文块的引用位置。点击一项可回到发出引用的正文块。

引用页的 Markdown 导出保留可回到原工作空间的知页链接。原生备份恢复到独立空间时，内部页面和块的稳定标识会一并恢复，引用会指向恢复空间中的对应内容。[数据格式](数据格式.md)
