# K16 原生内容包合并导入

实施[开发计划 v2.0](../../../个人资源管理系统_完整开发Plan_v2.0.md)第 5.1、5.3 节与 A07。通过「备份与恢复 → 合并内容包」将 ZIP v2–v7 或旧版内容 JSON 导入当前工作空间。

- 用两份具有相同原始 ID 的合成库复现合并缺口。核对新分支中的页面、各修订、数据库、属性选项、关系、公式、视图、模板、引用和附件。核对目标库原对象及授权。
- 复用内容包的校验和恢复写入逻辑。先验证源清单和原件，在临时文件中保存校验过的原件。一次 SQLite 事务发布页面和资源，沿用原有全文索引与变更触发器。
- 包内结构化引用按所属页面、数据库或模板重映射。没有目标的链接保持不可用。未知块携带原负载并获得新的块标识。源收藏与导入凭据随对象映射，已有收集箱和最近访问保持原样。
- 新版桌面 ZIP 清单声明历史范围、排除项及降级项。读取保留 v2–v6。使用现有迁移批次记录取消和失败，复用 SQLite 升级快照。用损坏原件、数据库写入失败和中途取消验证无半份内容发布。
- 完成桌面操作、使用文档、真实 Core 浏览器联调与原生恢复复验。过程、问题、版本和验收证据保存在开发目录。
