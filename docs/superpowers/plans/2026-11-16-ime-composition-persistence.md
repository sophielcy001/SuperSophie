# A02 输入法组字与保存

依据设计第 2.1、2.2 和 9.1 节。标题与正文允许输入法暂时呈现候选字符。自动保存、修订与结构化草稿应使用用户已经确认的内容。

1. 在 `scripts/verify-keyboard.mjs` 中用现有生产前端和真实 Core 验收链驱动标题与正文组字。跨过自动保存间隔后读取 SQLite 当前修订，分别验证取消和提交。保留修复前结果。
2. 在 `PageEditor.tsx` 收敛组字阶段的编辑器状态与提交时机。确认、取消后继续走现有保存队列。核对立即保存、导航、失败缓冲和块 ID。
3. 运行前端测试、完整浏览器回归和构建。记录系统版本、验证入口及原生 Windows 待验收项。
