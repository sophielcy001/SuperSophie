# K16 HTML 导出与内容包历史

[开发计划 v2.0](../../个人资源管理系统_完整开发Plan_v2.0.md)第 4.4 节列出 HTML 文件和降级报告，第 5.3 节允许内容包选择历史。

1. 在 `apps/desktop/src-tauri/src/files.rs` 增加实际 HTML 文件与相对原件的回归。共享已保存页的导出文件流程，先写并同步原件和报告，再发布正文文件。
2. 在 `crates/core/src/markdown.rs` 复用既有内容投影、逐块转换和链接映射。HTML 用现有 CommonMark 解析器的 HTML 功能，过滤原始标签与 URI。页面引用生成知页定位链接。用 Chromium 离线打开文件并核对正文、原件和报告。
3. 在 `crates/core/src/archive.rs` 增加历史选择。省略较早修订时保留每页的当前快照及其修订号，沿用兼容的内容 ZIP 格式。新增测试恢复两类包并验证继续编辑。
4. 桌面在页面操作增加「导出 HTML」，备份面板提供内容包的历史选项并默认勾选。整库恢复包继续按恢复流程保存完整快照。运行生产前端、Core、API／MCP 与原生文件面板复验。
