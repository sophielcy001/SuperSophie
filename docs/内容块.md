# 正文内容块

从页面的「插入」菜单选择内容块。在空白段键入 `/` 也可打开同一个菜单。

- 折叠块有可编辑标题和正文。手动展开或收起会随页面保存。点击目录、搜索结果或源块链接时，知页会临时展开所在折叠，保留之前保存的状态。
- 提示块提供「说明」「提示」「警告」三种样式。内容可继续使用段落、标题及其他正文块。
- 公式块保存 LaTeX 源码并在本机排版。编辑器允许保存格式有误的公式，并在预览处显示原文和错误提示。KaTeX 0.19.1 及字体随应用分发。应用限制公式最多 4,096 个 UTF-8 字节、宏最多展开 256 次，并关闭受信任命令。[KaTeX 版本](https://github.com/KaTeX/KaTeX/releases/tag/v0.19.1) [KaTeX 选项](https://katex.org/docs/options.html)
- 目录从该页正文的一至三级标题生成。点击条目可跳到对应块。标题变化后目录自动刷新。
- 附件块从本页附件列表选择原件。可在选择时添加文件。点击卡片可进入附件预览或另存原件。重命名后卡片更新，附件 ID 保留。
- 数据库视图复用同工作空间中保存的视图。通过卡片可打开原视图。[数据库视图指南](数据库视图.md)

## Markdown 导出示例

以下是这六个块依次导出的正文。折叠导出完整正文。公式的代码围栏会避开 LaTeX 源码中的反引号。目录成为按实际标题层级缩进的列表。桌面生成的附件目录名含随机后缀，导出的 Markdown 和原件目录一起移动。

目录中的 `导出报告.txt` 按正文块 ID 说明实际转换，同时保存页面和块引用的原始知页链接，以及原件的相对路径和 SHA-256。没有正文附件或封面时，报告单独放入同目录的 `zhiye-md-…` 文件夹。[通用导出格式](数据格式.md#通用导出)

~~~~markdown
> **换算过程**
>
> ### 实验参数

> [!TIP]
>
> 核对实际用量。

```math
\frac{a}{b}
```

**目录**

- 实验参数

[附件](<zhiye-files-r8cK2a/f0403b5c-0a84-4035-bd7f-9be705f659fa.txt>)

> ［数据库视图随原生工作空间包保留］
~~~~

REST 分页 Markdown 对目录显示 `> ［目录按当前页面标题生成］`，对可读附件和数据库视图提供 API 路径，并返回 `markdown_approximation`。有 `assets:read` 且能读取源页面时，可以另行下载附件。缺少该权限，附件使用通用占位，容器中可读的子块仍响应。原生 ZIP 保存原始块、附件与视图配置。[本机 API](本机API.md#正文内容块)

## HTML 导出

在「页面操作 → 导出 HTML」保存离线网页及配套目录。正文的层级、表格和图片可以在浏览器阅读。折叠中的内容随引用展示，公式显示 LaTeX 源码。页面和块链接指向知页源位置，原件保持相对路径。配套目录的报告写明实际块转换和每份原件的 SHA-256。[通用导出格式](数据格式.md#通用导出)
