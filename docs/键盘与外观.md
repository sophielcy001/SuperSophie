# 键盘与外观

打开窗口后按 Tab 可选中「跳到页面内容」，按 Enter 将焦点移到正文区域。继续按 Tab 可进入标题和正文。用键盘进入标题或正文时显示焦点轮廓；开始输入或用指针点击后只保留插入光标，其他控件的键盘焦点始终有可见轮廓。弹窗中的 Tab 和 Shift+Tab 循环浏览当前弹窗。按 Esc 可关闭空闲的弹窗或已经展开的下拉菜单，并回到打开入口。[WAI 弹窗模式](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/) [可见焦点](https://www.w3.org/WAI/WCAG22/Understanding/focus-visible.html)

正文不再常驻工具栏。选中文字或图片时，格式条浮在选区上方，提供「插入」、转换块类型（按钮显示当前类型，如「正文」）、加粗、斜体、下划线、删除线、行内代码、文字颜色、网页链接、引用页面和图片说明。颜色菜单与 Notion 相同，有灰、棕、橙、黄、绿、蓝、紫、粉、红九种文字颜色和背景色，两者可以叠加，选「默认」清除。导出 Markdown 时颜色不保留，文字照常导出。没有选中内容时，在正文中按 Alt+F10 可打开格式条并把焦点移到第一个按钮，Tab 在按钮间移动，Esc 关闭展开的菜单或格式条并回到正文。保存状态显示在窗口顶栏。

指针停在正文块上时，左侧出现「+」和拖动手柄 ⋮⋮。点「+」会在下方新建一行并打开插入菜单；拖动手柄可移动块；单击手柄打开块菜单，可创建副本、上移、下移、删除，把文字块转换为其他类型，或在「颜色」中给整行设置文字颜色或背景色（正文、标题和列表项的文字，九种颜色与格式条相同）。在正文中按 Ctrl+/（macOS 为 ⌘/）可用键盘打开同一菜单，按 ↑／↓ 选择，Enter 执行，Esc 回到正文。转换列表项时只改变这一项，前后的条目留在原列表。

与 Notion 相同，在正文中按 Esc 会选中光标所在的整块（浅蓝底色）。选中后按 ↑／↓ 选择上一块或下一块，Delete 或退格删除，Ctrl+C／⌘C 复制，Ctrl+D／⌘D 创建副本，Enter 回到块末尾继续输入。专注模式下，块已选中时再按一次 Esc 退出专注模式。按 Shift+↑／↓ 把选择扩展到相邻的多块，Delete 或退格一次删除这些整块（可撤销），Ctrl+C／⌘C 复制它们，↑／↓ 或 Esc 回到单块。选中整块后直接输入文字，会在这一块末尾接着写，不会覆盖它。点击正文下方的空白处，会在最后一行继续输入（最后一行不是空行时先新起一行）。正文和标题关闭了系统的自动大写和自动更正。选中整块后按 Tab 会离开正文。

在文字块中按 Tab 会把它缩进为上一块的子块（左侧留出缩进），Shift+Tab 取消缩进；与 Notion 的数据结构相同，缩进的块保存为上方正文或标题的子块，导出 Markdown 时依次跟在原块之后；第一块没有可以归属的上一块，此时 Tab 照常移动焦点。列表和表格中的 Tab 保持原有行为。斜杠菜单的「两列」「三列」插入分栏，每栏可放任何块；拖动两栏之间的空隙可调整栏宽（每栏至少约 10%），窗口较窄时分栏上下排列。

选中文字后点格式条的「评论」或按 Ctrl+Shift+M（⌘⇧M）添加评论，被评论的文字显示黄色底线。评论和回复中输入 `@` 加页面名称可提及页面（↑／↓ 选择，Enter 插入），显示为可点击的页面链接；被提及的页面在「反向链接」中会列出这条评论所在的块。光标停在其中时，下方显示评论卡片，可「回复」（回复按顺序列在评论下面，最多 50 条）、编辑或「解决」（移除评论及回复）。页面右上角「页面操作」中的「评论」列出本页全部评论及被评论的文字，点击即跳到该处。评论只保存在知页中，导出时保留文字、不写评论。

在空位置粘贴一个网址后，下方出现「保留为链接」和「书签卡片」两项（↑／↓ 选择，Enter 确认，继续输入则保留链接）。与 Notion 相同，选「书签卡片」后会自动访问该网址，读取标题、摘要和预览图；读取不到时卡片显示网址。书签卡片也可从斜杠菜单的「书签」创建，可填写标题，保存后自动访问该网址，读取网页标题、摘要和预览图（预览图最大 5 MiB，存为本页附件，显示在卡片右侧）；也可以在保存前按「读取网页标题」先看到标题。之后打开页面时预览图从本地附件读取，不再联网。粘贴网址时不会联网。卡片显示标题和网址，按住 Ctrl 或 ⌘ 点击打开。

使用标题按钮浏览页面树时，按 ↑／↓ 移动焦点，Home／End 跳到当前可见条目的首尾。按 → 展开分支或进入它的第一个子页，按 ← 折叠可折叠的分支或返回上级。Enter 打开当前页，页面加载后仍可在树上继续导航。「显示更多页面」会加载下一批同级页面。批量选择时可用 Tab 找到复选框。[WAI 展开式导航](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/examples/disclosure-navigation/)

在搜索框中按 ↑／↓ 选择结果，输入框会关联高亮结果的顺序和标题，PDF 结果还带页码。按 Enter 打开结果。在行首或空格后输入 `/` 唤出插入菜单，标题、列表和引用中同样可用，代码块中不会唤出。按 ↑／↓ 选择块类型，按 Enter 插入。在 `/` 后继续输入可筛选，支持中文名、英文和拼音首字母，例如 `/bt` 只列出三种标题、`/todo` 为待办清单；有输入时默认选中第一项，直接回车即插入。只输入 `/` 且未用方向键选择时，直接回车按正文输入处理。与 Notion 相同，空行中的命令把这一行变成所选类型；在已有文字后输入的命令会删去命令文字，在下方新建所选的块。按 Esc 关闭菜单后，这个 `/` 保留为普通文字。空段落显示「输入 / 唤出命令…」占位提示。

斜杠菜单中的「页面」（`/page`、`/ym`）会新建当前页的子页面，在命令位置插入指向它的链接并打开子页面，光标在标题中；「链接到页面」打开页面选择窗口。数据库页面的说明区不提供「页面」。

与 Notion 的内嵌数据库相同，斜杠菜单中的「数据库」「表格视图」「看板视图」「日历视图」「列表视图」「画廊视图」「时间线视图」（如 `/rili`、`/kanban`）会在当前页下新建一个数据库，并在命令位置显示所选视图。日历数据库自带「日期」属性，时间线自带「日期」和「结束日期」。点击内嵌数据库的名称可直接改名，「打开数据库」进入它自己的页面。在内嵌数据库中可以切换和新建视图、新建记录、修改属性和拖动，与打开数据库页面时相同；切换的视图随这一页保存。「关联已有数据库」把已有数据库的某个视图放到正文中。数据库页面的说明区不提供这些命令。

页面链接与 Notion 的提及相同，显示目标页面的当前标题：子页面改名后，返回上级即可看到新标题，并在这一页下次保存时写入。导入的 Markdown 链接等自带文字的链接保留原文字。目标页面进入回收站后，链接显示为灰色删除线。

输入 `@` 或 `[[` 后接页面名称的一部分，会列出匹配的页面（按最近修改排序，最多 8 个），Enter 插入页面引用；最后一项「搜索全部页面…」打开完整的页面选择窗口。`@` 紧跟在英文字母或数字后面时不会唤出（如电子邮件地址）；没有匹配的页面时，Enter 按正文输入处理。

除标准 Markdown 快捷输入（`#`、`-`、`1.`、`[]`、```` ``` ````、`---` 等）外，正文按 Notion 的习惯处理：行首 `> ` 加空格生成折叠块，已有文字成为折叠标题，标题为空时光标进入标题，回车进入折叠内容；行首 `"` 加空格生成引用；中文输入法下的 `》`、`“`、`【】` 同样有效。标题开头按退格先变回正文。代码块左上角在指针停留时显示语言选择，所选语言随页面保存。

记录页上方的属性可直接点击修改：文本、数字、链接和日期在原位输入，回车或移开焦点保存，Esc 取消；状态和单选从下拉列表选择；复选框直接勾选。其他类型和完整表单从属性区的「编辑属性」进入。数据库表格中，单击标题单元格即可改标题（回车或移开焦点保存，Esc 取消），指针停在标题上时出现的「打开」进入记录页；文本、数字、链接、日期、状态、单选和复选框单元格可直接点击修改，规则与记录页相同；指针停在某行或用 Tab 进入该行时出现编辑按钮。表格底部「新建一条」、看板每列底部的「新建」、画廊末尾的新建卡片和日历某天的「+」都在原处新建记录，光标停在标题输入框中，与 Notion 一样不离开视图；工具栏的「新建」仍新建并打开记录页（内嵌数据库中同样原处新建）。日历中指针停在某天时左上角出现「+」（也可按 Tab 到达，辅助技术读作「在 日期 新建记录」），新建的记录自动填入当天；带时区的日期时间属性填入当天 UTC 零点。看板每列新建的记录带有该列状态（辅助技术读作「在「列名」中新建记录」），卡片可以拖到别的列，松开后改为该列的状态。

日历中有结束日期的记录显示为一整条，跨周时每周一段；没有结束日期的记录占一天。拖动条中间整体移动，拖动左右边缘改开始或结束日期，松开时保存。日历视图尚未设置结束日期属性时，第一次拖动边缘会使用名为「结束日期」的同类型属性，没有则自动新建，并记入视图设置（也可在「视图设置」中选择）。Notion 把起止日期存在同一个日期属性中；知页用两个属性，与时间线相同。时间线的条同样可以拖动边缘调整起止日期。中文输入法组字期间保留输入法对组合键的处理。

标题或正文出现候选文字时，保存状态显示「输入法组字中」。选词确认，文字进入自动保存和修订。取消组字，页面回到之前的文字。若已有保存错误，错误和草稿操作继续显示。[保存故障与草稿](故障恢复.md)

任务清单的复选框向辅助技术提供当前任务首段的中文名称，包含其中的页面引用。父任务和子任务各自命名，首段为空时显示「空白任务」。复选框获得焦点后可按空格切换勾选状态。

## 命令面板和专注模式

用顶部的「命令面板」或快捷键打开面板，输入命令名称的一部分，按 ↑／↓ 和 Enter 选择并执行。有快捷键的命令会在右侧显示快捷键。搜索和命令面板显示在窗口上方，按 Esc 或点击面板外部关闭。面板可以新建页面、打开搜索、导入资料、备份、切换主题或打开当前页历史。列表随当前工作空间和页面变化。[WAI 组合框模式](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/)

专注模式收起侧栏和页面操作区，保留正文编辑、保存状态、命令面板和「退出专注模式」入口。再次按模式快捷键或 Esc 返回原布局。已打开的弹窗和斜杠菜单先响应 Esc。

## 主题

从「切换工作空间 → 外观」选择「跟随系统」「使用浅色主题」或「使用深色主题」，也可直接在命令面板搜索这些选项。显式选择保存到当前桌面配置，重开后会继续使用。跟随系统时，运行中也会更新。系统启用强制颜色时保留当前选中项目的轮廓，减少动态效果时缩短动画和折叠过渡。

界面参照 Notion 的阅读习惯：使用系统字体（Windows 为 Segoe UI 与微软雅黑，macOS 为苹方），正文 16px，标题 40px；浅色主题为白色正文区和暖灰侧栏，深色主题为接近黑色的中性灰。选中项和悬停使用中性灰，链接、复选框和主要按钮使用蓝色。
