# 键盘与外观

打开窗口后按 Tab 可选中「跳到页面内容」，按 Enter 将焦点移到正文区域。继续按 Tab 可进入标题、编辑工具和正文。窗口内的键盘焦点有可见轮廓。弹窗中的 Tab 和 Shift+Tab 循环浏览当前弹窗。按 Esc 可关闭空闲的弹窗或已经展开的下拉菜单，并回到打开入口。[WAI 弹窗模式](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/) [可见焦点](https://www.w3.org/WAI/WCAG22/Understanding/focus-visible.html)

## 快捷键

| 操作 | Windows | macOS |
|---|---|---|
| 搜索页面、正文或 PDF | Ctrl+K | ⌘K |
| 打开命令面板 | Ctrl+Shift+P | ⌘⇧P |
| 切换专注模式 | Ctrl+Shift+F | ⌘⇧F |
| 立即保存 | Ctrl+S | ⌘S |
| 同级块上移或下移 | Alt+Shift+↑／↓ | Option+Shift+↑／↓ |

使用标题按钮浏览页面树时，按 ↑／↓ 移动焦点，Home／End 跳到当前可见条目的首尾。按 → 展开分支或进入它的第一个子页，按 ← 折叠可折叠的分支或返回上级。Enter 打开当前页，页面加载后仍可在树上继续导航。「显示更多页面」会加载下一批同级页面。批量选择时可用 Tab 找到复选框。[WAI 展开式导航](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/examples/disclosure-navigation/)

在搜索框中按 ↑／↓ 选择结果，输入框会关联高亮结果的顺序和标题，PDF 结果还带页码。按 Enter 打开结果。正文空段输入 `/` 后，按 ↑／↓ 选择块类型，按 Enter 插入。未用方向键选择时，直接回车按正文输入处理。中文输入法组字期间保留输入法对组合键的处理。

标题或正文出现候选文字时，保存状态显示「输入法组字中」。选词确认，文字进入自动保存和修订。取消组字，页面回到之前的文字。若已有保存错误，错误和草稿操作继续显示。[保存故障与草稿](故障恢复.md)

任务清单的复选框向辅助技术提供当前任务首段的中文名称，包含其中的页面引用。父任务和子任务各自命名，首段为空时显示「空白任务」。复选框获得焦点后可按空格切换勾选状态。

## 命令面板和专注模式

用顶部的「命令面板」或快捷键打开面板，输入命令名称的一部分，按 ↑／↓ 和 Enter 选择并执行。面板可以新建页面、打开搜索、导入资料、备份、切换主题或打开当前页历史。列表随当前工作空间和页面变化。[WAI 组合框模式](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/)

专注模式收起侧栏和页面操作区，保留正文编辑、保存状态、命令面板和「退出专注模式」入口。再次按模式快捷键或 Esc 返回原布局。已打开的弹窗和斜杠菜单先响应 Esc。

## 主题

从「切换工作空间 → 外观」选择「跟随系统」「使用浅色主题」或「使用深色主题」，也可直接在命令面板搜索这些选项。显式选择保存到当前桌面配置，重开后会继续使用。跟随系统时，运行中也会更新。系统启用强制颜色时保留当前选中项目的轮廓，减少动态效果时缩短动画和折叠过渡。
